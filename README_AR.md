# Print Cost & Profit

**حل متكامل لحساب التكاليف ومراقبة الإنتاج وإدارة أعمال الطباعة ثلاثية الأبعاد.**

يساعد Print Cost & Profit على معرفة التكلفة الفعلية لكل طبعة، وتحديد أسعار بيع مناسبة، ومراقبة الطابعات المتوافقة، وإدارة مخزون الخيوط وتنظيم العمل اليومي.

### التثبيت على Windows
1. افتح [Releases](https://github.com/nilose2014/PrintCostProfit/releases).
2. نزّل أحدث مثبت `.exe` أو ملف ZIP المتاح.
3. شغّل المثبّت أو فك ضغط ZIP كاملًا داخل مجلد يسمح بالكتابة.
4. شغّل التطبيق من الاختصار أو نص البدء المرفق.
5. إذا لم يفتح المتصفح، انتقل إلى `http://127.0.0.1:8700/`.
6. احتفظ بملفات HTML وJavaScript وCSS والخادم معًا.

يجب أن يعمل الخادم المحلي أثناء الاستخدام. بعد التحديث، أوقف الخادم القديم وشغّل الخادم من المجلد المحدّث ثم أعد التحميل باستخدام `Ctrl + F5`. أنشئ نسخة احتياطية قبل استبدال الملفات ولا تحذف مجلد البيانات.

### التثبيت على Linux (Ubuntu وDebian ومشتقاتهما)
1. نزّل الحزمة من [فرع Linux](https://github.com/nilose2014/PrintCostProfit/tree/linux) أو [Releases](https://github.com/nilose2014/PrintCostProfit/releases).
2. فك ضغط الحزمة وافتح الطرفية في المجلد الرئيسي.
3. نفّذ:
   ```bash
   chmod +x linux/iniciar_linux.sh
   ./linux/iniciar_linux.sh
   ```
4. افتح `http://127.0.0.1:8700/`.

نفّذ الأوامر في طرفية Linux؛ وفي WSL استخدم Ubuntu وليس PowerShell. يلزم Python 3 وSQLite. حافظ على بنية المجلدات. تحفظ بيانات المستخدم منفصلة عن ملفات البرنامج. لا تتجاهل فشل اختبارات البدء.

### التشغيل الأول والاتصال بالطابعة
ابدأ الخادم قبل فتح الموقع. يجب أن يكون الكمبيوتر والطابعة قابلين للوصول عبر الشبكة المحلية. اضبط Moonraker باستخدام عنوان LAN والمنفذ. يمكن حفظ الإعدادات والطابعة مطفأة، لكن المراقبة المباشرة تتطلب اتصالها. يعتمد تكامل Snapmaker Orca على سير العمل المحلي المدعوم ونص المعالجة اللاحقة المرفق.

## ما هو Print Cost & Profit؟

يجمع الجوانب التقنية والتجارية للطباعة ثلاثية الأبعاد. إضافة إلى المادة والوقت، يأخذ في الحسبان الكهرباء واستهلاك الآلة والصيانة والعمالة والتشطيب والطباعات الفاشلة والمخزون وسعر البيع النهائي.

يتيح سير العمل استيراد بيانات G-code أو إدخالها يدويًا، وحساب تكلفة الإنتاج الحقيقية، وتحديد الربح والسعر المقترح، والتحقق من المواد والطابعة، وحفظ التقييمات والمستندات، ومتابعة الإنتاج والمخزون والصيانة والماليات.

## الميزات الرئيسية

### 1. حاسبة تكاليف الطباعة
تأخذ في الحسبان استهلاك الخيط بالجرام وسعر الكيلوغرام ومدة الطباعة والكهرباء واستهلاك قيمة الطابعة وتكاليف الآلة والصيانة والعمالة والتحضير والتكاليف الإضافية والطلاء والتشطيب لكل وحدة واحتياطي الطباعات الفاشلة. تعرض الربح المستهدف والسعر المقترح والتكلفة والربح لكل وحدة والهامش. تميّز بين **تكلفة الإنتاج** و**سعر البيع** و**الربح** و**الهامش**.

#### بيانات G-code وبرنامج التقطيع
يمكن لتكامل Orca استيراد اسم الملف والمواد والألوان ورموز HEX والاستهلاك والوقت المقدر والصور المصغرة المتاحة. راجع البيانات والمطابقة قبل الحساب، خصوصًا في المشاريع متعددة المواد أو الألوان.

#### مقارنة الأسعار والتقييمات المحفوظة
قارن سيناريوهات الأسعار وتأثير تغيير هدف الربح أو إضافة مبلغ. يمكن حفظ التقييمات.

### 2. لوحة المعلومات
نظرة عامة على المبيعات والتكاليف والأرباح والرسوم المالية والمخزون وحالة الطابعات والإنتاج والنشاط الأخير. توجد التفاصيل في الأقسام الخاصة بها.

### 3. مراقبة الطابعات — Snapmaker U1 / Moonraker
تربط الطابعات المتوافقة عبر الشبكة المحلية وMoonraker. تشمل الوظائف اكتشاف الطابعة وإدخال IP يدويًا وحفظ الاتصال وحالة الاتصال وقراءة حالة الطباعة وتقدمها وعرض المهمة النشطة واسم الملف واستهلاك الخيط المتاح وقائمة الملفات والصور المصغرة واختيار طابعة من عدة طابعات وإرسال بيانات الطباعة النشطة إلى الحاسبة.

يجب أن يصل الكمبيوتر إلى الطابعة عبر الشبكة المحلية. قد يمنع جدار الحماية أو عزل الشبكة أو IP غير الصحيح أو عدم توفر Moonraker المراقبة.

### 4. مخزون الخيوط
يسجل العلامة التجارية والمادة (PLA وPETG وغيرها) واسم اللون ورمز HEX والوزن الأولي والمتبقي والسعر لكل كيلوغرام والكمية. يقارن مواد وألوان G-code بالبكرات المسجلة. يجب مراجعة المطابقات غير المؤكدة. تعتمد تنبيهات النقص على تحديث الأوزان.

### 5. الطابعات والملفات التعريفية
إعداد الطابعات والاتصالات واكتشافها عبر الشبكة عند توفر ذلك وحفظ بياناتها وعرض حالتها وربط الإنتاج والمحاسبة بها. يركز سير العمل على Snapmaker U1؛ وقد تحتاج الأجهزة والبرامج الثابتة الأخرى إلى واجهات Moonraker متوافقة ولم يتم التحقق منها بالضرورة.

### 6. مركز الصيانة
ينظم التنظيف وتشحيم المحاور وفحص الأحزمة والأدلة والـ hotend والفوهات والطارد وتغذية الخيط والمراوح والتبريد ومنصة الطباعة والكابلات والموصلات. يمكن تسجيل الأعمال وحالتها. اتبع دائمًا دليل الشركة المصنعة وإرشادات السلامة.

### 7. عروض الأسعار والطلبات والفواتير
إنشاء عروض الأسعار وحفظها وإدارة الطلبات والفواتير وربط العملاء وعرض التفاصيل والإجماليات وإنشاء PDF وتحويل العرض إلى فاتورة عندما يدعم سير العمل ذلك. تحقق من الترقيم والضرائب والعملة والعميل وملف PDF قبل الإرسال.

### 8. العملاء
حفظ بيانات العملاء وربطها بالمستندات التجارية لتقليل الإدخال المتكرر وتنظيم عروض الأسعار والطلبات والفواتير.

### 9. المحاسبة
تسجيل الحركات ومراجعة الإيرادات والتكاليف والأرباح، وبحسب الإعدادات حسب الطابعة. طابق البيانات مع المحاسبة الرسمية والالتزامات الضريبية. التطبيق لا يقدم استشارات محاسبية أو ضريبية.

### 10. كتالوج المنتجات
تنظيم المنتجات المصنّعة أو المباعة. عند توفر الوظائف، تربط واجهة المنتجات وميزات QR المنتج المادي بمعلومات الكتالوج.

### 11. سجل النشاط والتشخيص
تساعد السجلات المحلية على تشخيص الخادم واتصال الطابعة وAPI والاستيراد والتكامل والنسخ الاحتياطي والتخزين. عند الإبلاغ عن مشكلة، أرفق الإصدار والنظام والخطوات والسجلات بعد إزالة البيانات الخاصة.

### 12. النسخ الاحتياطي والاستعادة
تخزين محلي مع النسخ والاستعادة في الإصدارات المدعومة. يوفر خادم Linux واجهة API للّقطات والتحكم بالمراجعات والنسخ والسجلات، ولـ Windows خادمه وتخزينه الخاصان. أنشئ نسخة قبل التحديث، واحفظها خارج مجلد البرنامج، ولا تعدّل قاعدة البيانات أثناء تشغيل التطبيق.

### 13. الخيارات والواجهة
تجمع الإعدادات. وفقًا للإصدار يمكن تنظيم الأقسام وإخفاء الحقول وتغيير ترتيب اللوحات.

### 14. ثماني لغات
تُدار النصوص مركزيًا في `js/traducciones.js`: الإسبانية والإنجليزية والفرنسية والألمانية والإيطالية والبولندية والعربية بدعم RTL والصينية المبسطة. يجب إضافة الحقول والحوار والأزرار والتنبيهات والأخطاء الجديدة إلى النظام المركزي وترجمتها.

## سير العمل المعتاد
1. جهّز المهمة في برنامج التقطيع وأنشئ G-code.
2. استورد البيانات عبر Orca أو أدخلها يدويًا.
3. راجع المواد والألوان واربطها بالمخزون.
4. تحقق من الطابعة والخيط المتاح.
5. احسب المادة والوقت والكهرباء والآلة والعمالة والتشطيب.
6. حدد سعر البيع وراجع الهامش.
7. احفظ عرض السعر واربطه بالعميل.
8. راقب الطباعة.
9. سجّل البيع أو الفاتورة وراجع النشاط المالي.
10. حدّث المخزون والصيانة.

## متطلبات النظام
**Windows:** نظام Windows متوافق 64 بت، وصلاحيات تشغيل وكتابة البيانات، واتصال بالشبكة المحلية للطابعة وإنترنت لـ GitHub.

**Linux:** Ubuntu أو Debian أو مشتقاتهما، Python 3 وSQLite وصلاحية تنفيذ النص واتصال بالشبكة المحلية.

**الطابعة:** اتصال متوافق، وإمكانية الوصول إلى Moonraker محليًا، وعنوان IP صحيح، وتكامل Orca مضبوط وفق الحزمة.

## الإصدارات والتحديثات
إصدار Windows المستقر وحزمة Linux الموضحان هما **v1.4**. قبل التحديث، أنشئ نسخة احتياطية، ونزّل الحزمة الصحيحة، وأوقف الخادم، وحدّث الملفات، وشغّل الخادم من المجلد الجديد وتحقق من الإصدار. لا تشغّل خادمين على المنفذ نفسه. العنوان الافتراضي: `127.0.0.1:8700`.

## استكشاف الأخطاء
- **التطبيق لا يفتح:** تحقق من الخادم والطرفية/PowerShell وافتح `http://127.0.0.1:8700/` وتحقق من المنفذ 8700.
- **إصدار غير صحيح:** أوقف الخادم القديم وشغّل الصحيح وافحص `http://127.0.0.1:8700/api/version` وملف `VERSION` ثم أعد التحميل بـ `Ctrl + F5`.
- **الطابعة غير متصلة:** تحقق من الطاقة والشبكة وIP وMoonraker والجدار الناري؛ جرّب IP يدويًا.
- **بيانات أو صور G-code مفقودة:** راجع G-code وما يصدّره برنامج التقطيع، وتحقق من المادة واللون والوزن والوقت.
- **فشل اختبارات Linux:** شغّل النص من جذر المشروع وتحقق من Python 3 وSQLite واحتفظ بالخطأ كاملًا.
