## 1. التنزيل

نزّل البرنامج دائمًا من إصدارات GitHub الرسمية.

### Windows 10 / 11 — الإصدار 2.0

**ملف ZIP للتثبيت:** `PrintCostProfit-Setup-v2.0.zip`  
[إصدار Windows 2.0](https://github.com/nilose2014/PrintCostProfit/releases/tag/v2.0)

1. نزّل ملف ZIP واختر **Extract All**.
2. افتح المجلد المستخرج.
3. شغّل `PrintCostProfit-Setup.exe` واتبع معالج التثبيت.

**ملف ZIP المحمول:** `PrintCostProfit-Portable-v2.0.zip`  
[إصدار Windows 2.0](https://github.com/nilose2014/PrintCostProfit/releases/tag/v2.0)

1. نزّل ملف ZIP وفك ضغطه في مجلد دائم.
2. شغّل `PrintCostProfit-Portable.exe` من المجلد المستخرج.

لا تشغّل الملفات التنفيذية من داخل ZIP. احتفظ بجميع ملفات التطبيق المستخرجة معًا.

### Linux — الإصدار 1.4

[إصدار Linux 1.4](https://github.com/nilose2014/PrintCostProfit/releases/tag/linux-v1.4)

**Debian / Ubuntu:** `printcostprofit_1.4.1_amd64.deb`  
[تنزيل .deb](https://github.com/nilose2014/PrintCostProfit/releases/download/linux-v1.4/printcostprofit_1.4.1_amd64.deb)

```bash
sudo apt install ./printcostprofit_1.4.1_amd64.deb
```

يمكنك أيضًا النقر مرتين على ملف `.deb` واستخدام مدير الحزم.

**AppImage:** `PrintCostProfit-Linux-x86_64.AppImage`  
[تنزيل AppImage](https://github.com/nilose2014/PrintCostProfit/releases/download/linux-v1.4/PrintCostProfit-Linux-x86_64.AppImage)

```bash
chmod +x PrintCostProfit-Linux-x86_64.AppImage
./PrintCostProfit-Linux-x86_64.AppImage
```

حزم Linux مخصصة لأنظمة AMD64 ذات 64 بت. **إصدار Windows هو 2.0، أما إصدار Linux المنشور فهو 1.4. وهما مساران منفصلان للإصدارات.**

## 2. تنبيه أمان Windows

يتم توزيع ملفات Windows حاليًا دون شهادة تجارية لتوقيع التعليمات البرمجية. قد يعرض SmartScreen أو برنامج أمان آخر تحذيرًا. تحقق من مصدر التنزيل الرسمي. لا تتجاهل اكتشافًا حقيقيًا لمكافحة الفيروسات ولا تتجاوز التحذير إذا تعذر التحقق من مصدر الملف.

## 3. الميزات الرئيسية

- **حاسبة تكاليف الطباعة ثلاثية الأبعاد:** تقدّر تكاليف التصنيع وفق استهلاك الخيوط وسعر المادة ووقت الطباعة وتكاليف تشغيل الجهاز والإهلاك والصيانة والمصروفات المحددة.
- **السعر والربحية:** تعرض تكلفة الإنتاج المقدرة وسعر البيع والربح والهامش والسعر الموصى به. تعتمد النتائج على القيم المدخلة.
- **مخزون الخيوط:** إدارة العلامات التجارية والمواد والألوان وكميات البكرات والأسعار.
- **ملفات تعريف الطابعات:** حفظ معلمات الأجهزة المستخدمة في حساب التكاليف.
- **مراقبة الطابعات:** تم تأكيد التوافق الكامل مع Snapmaker U1. قد تعمل طابعات Moonraker أو Fluidd أو Mainsail الأخرى حسب الإعدادات والوظائف المدعومة.
- **تكامل برامج التقطيع:** مصمم لـ Snapmaker Orca وOrcaSlicer وCreality Print. تبلغ نسبة التوافق نحو 90% وقد تختلف حسب الإصدار والإعدادات؛ ولا يُضمن التوافق بنسبة 100%.
- **معالجة G-code:** قراءة معلومات الملف المتاحة ووقت الطباعة المقدر واستهلاك المادة المقدر وبيانات الخيوط. لا تعادل تقديرات برنامج التقطيع بالضرورة الاستهلاك الفعلي للطابعة.
- **عروض الأسعار والفواتير والمحاسبة:** أدوات لتنظيم المستندات التجارية والأنشطة المالية.
- **SQLite محلي:** يخزن Windows 2.0 البيانات محليًا باستخدام SQLite وElectron IPC.

## 4. بنية Windows — الإصدار 2.0

يحمّل Windows 2.0 الواجهة من ملفات Electron المحلية ولم يعد يستخدم جسر HTTP القديم المعتمد على PowerShell. تتواصل الواجهة مع SQLite عبر IPC. يتم الوصول إلى الطابعات المتوافقة عبر الشبكة باستخدام Moonraker. ويستخدم تدفق G-code الخاص بـ Orca مراقبة ملفات محلية تديرها Electron. لا تصف التعليمات القديمة الخاصة بخادم HTTP أو جسر PowerShell بنية Windows 2.0.

## 5. تكامل برنامج التقطيع

التكامل مخصص للتطبيقات المبنية على OrcaSlicer، وخاصة Snapmaker Orca وOrcaSlicer وCreality Print. قد تختلف أسماء القوائم حسب التطبيق والإصدار.

1. افتح برنامج التقطيع وحدد ملف تعريف الطابعة.
2. افتح إعدادات الطباعة وفعّل الوضع المتقدم عند الحاجة.
3. ابحث عن قسم **Others** وإعدادات نصوص المعالجة اللاحقة.
4. اتبع تعليمات التكامل المرفقة مع الحزمة المناسبة.
5. احفظ ملف التعريف وأنشئ G-code تجريبيًا وتحقق من وصول المعلومات المتاحة.

يستخدم Windows 2.0 مراقبة ملفات محلية تديرها Electron. لا تستخدم التعليمات القديمة التي تتطلب جسر HTTP في PowerShell.

## 6. شبكة الطابعة

بالنسبة إلى طابعات Moonraker المتوافقة، تأكد من اتصال الكمبيوتر والطابعة بالشبكة، واحصل على عنوان IP، وتحقق من الوصول إلى Moonraker واضبط الاتصال في التطبيق. تعتمد الوظائف على الطابعة والبرنامج الثابت والشبكة. Snapmaker U1 هي الطابعة المرجعية ذات التوافق الكامل المؤكد.

## 7. البيانات والنسخ الاحتياطية

يستخدم Windows قاعدة بيانات SQLite محلية. أنشئ نسخًا احتياطية بانتظام، وخاصة قبل التحديث. لا تحذف قاعدة البيانات أو تنقلها يدويًا أثناء تشغيل التطبيق. إذا فشلت تهيئة التخزين، احتفظ بقاعدة البيانات وافحص الخطأ قبل إدخال بيانات مهمة.

## 8. متطلبات النظام

- **Windows:** Windows 10 أو 11، بنظام 64 بت ومساحة كافية. يلزم اتصال بالشبكة لمراقبة الطابعات. لا تتطلب حزم المستخدم تثبيت Node.js أو Python يدويًا.
- **Linux:** AMD64 بنظام 64 بت. استخدم حزمة Debian على أنظمة Debian/Ubuntu المتوافقة أو AppImage.
- تكاملات اختيارية: Snapmaker Orca وOrcaSlicer وCreality Print والطابعات المتوافقة المتصلة بالشبكة.

لا تحذف بيانات التطبيق عند التحديث. لدى Windows وLinux مساران منفصلان؛ تحقق من الإصدار.

## 10. استكشاف الأخطاء

- **لا يبدأ Windows:** تحقق من فك ضغط ZIP بالكامل وبقاء الملفات معًا. سجّل الخطأ.
- **تحذير أمني:** تحقق من مصدر التنزيل ونتائج مكافحة الفيروسات. إصدار Windows غير موقّع حاليًا بشهادة تجارية.
- **فشل مراقبة الطابعة:** تحقق من الطاقة والشبكة وعنوان IP والوصول إلى Moonraker والإعدادات.
- **فشل التكامل:** تحقق من إصدار برنامج التقطيع والمعالجة اللاحقة وG-code واستقبال الملفات محليًا.
- **لا تُحفظ البيانات:** احتفظ بقاعدة البيانات وافحص تهيئة SQLite وسجّل الخطأ. لا تحذف البيانات كحل مؤقت.
- **لا يبدأ AppImage:** نفّذ `chmod +x` وشغّله من الطرفية وراجع الأخطاء. بالنسبة إلى `.deb`، تحقق من التثبيت والاعتماديات.
